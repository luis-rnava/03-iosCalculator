# 📱 iOS Calculator

Una calculadora clon de iOS construida con **React Native**, diseñada para ofrecer una experiencia fluida, moderna y visualmente atractiva tanto en dispositivos Android como iOS.

---

## 🚀 Características

- ✅ UI minimalista y responsiva inspirada en la app de calculadora de iOS  
- ⚙️ Lógica de operaciones básicas (suma, resta, multiplicación, división)  
- ♻️ Manejo de errores como divisiones por cero  
- 💅 Estilos adaptados a cada plataforma  
- 📱 Compatible con Android e iOS  

---

## 🧱 Tecnologías

- [React Native 0.79.2](https://reactnative.dev/)
- [TypeScript](https://www.typescriptlang.org/)

---

## 📦 Instalación

Cloná el repo y ejecutá:

```bash
npm install
```

## Uso
Para iniciar la app, ejecutá:

```bash
npm run android
```
